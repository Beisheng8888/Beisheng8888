## About Me

- 主要围绕 `Java / Spring Boot / MyBatis / Vue` 构建前后端分离应用。
- 以后端为核心，也能处理前端实现、联调链路、构建发布和工程落地。
- 更偏爱长期主义的开发方式，而不是只把功能堆到“能跑”为止。
- 我希望自己写出来的系统，既能交付，也能维护，还能继续长出来。

## Current Focus

- 复杂业务系统的模块设计与持续迭代
- 后端服务、数据层和接口边界的稳定性建设

- 让代码从“可用”逐步走向“可靠”和“好接手”
